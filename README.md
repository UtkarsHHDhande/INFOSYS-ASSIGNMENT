# Infosys Competitor Collaboration Finder

## Overview

This project is designed to find and display collaborations between Virgin Media and the competitors of Infosys. It uses web scraping techniques to gather information from search engines and news websites, providing a user-friendly interface to view and export the results.

## Features

- **Web Scraping**: Fetches collaboration information from Bing and Reuters.
- **Pagination**: Displays results in paginated format for better navigation.
- **Export Options**: Allows exporting results as CSV or JSON.
- **Responsive Design**: Works well on desktop and mobile devices.
- **Error Handling**: Provides clear error messages and feedback.


## Usage

- **Search**: The application automatically searches for collaborations between Virgin Media and the competitors of Infosys.
- **Pagination**: Use the pagination controls to navigate through results.
- **Export**: Click on the "Export CSV" or "Export JSON" buttons to download the results.
